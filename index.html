Intensité & récupération

Gros mouvements : 1–2 RIR, sans échec systématique. Isolations : 1–2 RIR ; dernière série parfois 0–1 si propre. Aucun ajout automatique de séries.

Supersets accessoires seulement si pratique. Mercredi : aucune paire de machines. Circuit samedi OFF par défaut si fatigue, grosse activité ou baisse de performance.

Calibration machines : RIR 4+ → +5–10 % ; RIR 2–3 → conserver ; RIR 1 → acceptable ; RIR 0/échec → −5–10 %. Appliquer manuellement selon le cran disponible.

Intensification à partir du 22 novembre : au plus une par séance, deux par semaine. Uniquement Pec Deck drop set, latérales partiels, curl câble rest-pause ou pushdown drop set. Jamais sur les mouvements lourds, presses, rowings, jambes ou Front Lever.

Charges machine indicatives : conserve la même machine, les réglages et la convention (total, par côté ou par main). Pour dips et tractions, saisis uniquement le lest ; 0 = PDC. Pour les maintiens : secondes et marge en secondes dans RIR.

Sauvegarde personnelle

Les séances et brouillons sont conservés sur cet appareil. Exporte régulièrement : effacer les données Safari, changer d’adresse du site ou d’appareil peut supprimer l’accès au stockage.
